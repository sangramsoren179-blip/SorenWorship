# SorenWorship

A Christian Song Lyrics App.

## About

SorenWorship is a project dedicated to building a platform for Christian song lyrics. Its goal is to make Christian songs easy to discover, access, and read.

The platform will provide song lyrics alongside relevant video links, making it easier for users to read, watch, and listen to Christian songs in one place.

## Planned Features

- **Browse Songs:** Explore a collection of Christian songs.
- **Search Songs:** Find songs by title or keywords.
- **Read Lyrics:** Access song lyrics in a clean and readable format.
- **Watch & Listen:** Watch and listen to songs through video links in the browser.
- **Favorites:** Save favourite songs for quick access.
- **Multiple Languages:** Support Christian songs in different languages.
- **Reading Customization:** Adjust text size and other reading preferences.
